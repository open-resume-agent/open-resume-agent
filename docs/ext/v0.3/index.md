# ORA A2A extension v0.3

An A2A Agent Card that lists this URI in `capabilities.extensions` declares that the agent represents a person under the Open Resume Agent specification and follows its rules (truthfulness, disclosure audiences, compliance, commitments and handoff).

**Params:** `document`, the URL of the agent's ORA document or agent file (public build), e.g. `/.well-known/resume-agent.md`.

- Specification: [/spec/](/spec/) (SPEC §14.3)
- Schema: [/schema/v0.3/resume-agent.schema.json](/schema/v0.3/resume-agent.schema.json)
