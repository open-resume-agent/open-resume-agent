# Roadmap

| Milestone | Target | Contents |
|---|---|---|
| **v0.3** | Nov 2026 | Agent file (`resume-agent.md`), deployment targets, output generation, reference tools |
| **v0.4** (current draft) | Q1 2027 | ORA's own résumé record, with JSON Resume as an export (RFC 0001); Python package `open-resume-agent` on PyPI (`ora build · validate · render · mcp`); reference MCP server on the MCP Registry; L2 conformance runner (any model plus an LLM grader); first external implementation (PopYourJob Builder) |
| **v0.5** | Q2 2027 | Job Agent counterpart spec (employer side) and an agent-to-agent negotiation protocol; normative mapping between claims and LER-RS / W3C VC; multilingual statements |
| **v0.6** | Q3 2027 | Revocation (claims, evidence, credentials); team and agency accounts; jurisdiction packs (EU, UK, IN, AE, AU) |
| **v1.0** | late 2027 | Stability freeze, three independent implementations, neutral governance (see `GOVERNANCE.md`) |

Open questions are tracked as issues labelled `spec` and proposals in `rfcs/`.
