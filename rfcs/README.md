# RFCs

Normative changes to ORA (anything that changes a MUST or SHOULD, the schema, a profile or a registry) go through an RFC.

1. Copy `0000-template.md` to `rfcs/0000-short-title.md` and open a pull request labelled `rfc`.
2. Discussion stays open for at least **14 days**.
3. If accepted, the RFC gets a number, is merged, and its changes land in `SPEC.md`, the schema, `CHANGELOG.md` and at least one conformance case.
4. Rejected RFCs are closed, with the reason recorded.
